You might be aware, that a critical security vulnerability, called [PHP2Shell](https://en.wikipedia.org/wiki/PHP2Shell), has been disclosed yesterday in PHP.
This technology drives large parts of the internet and the vulnerability allows to execute malicious code on comprimised servers.
ESMira is also built on PHP, meaning all ESMira servers are at risk and need to be updated as soon as possible.

> **Important**: This is not a vulnerability in ESMira itself but the technology that allows you to run it. As a result, the server update through the ESMira web interface will **not** resolve this vulnerability.

## How to fix PHP2Shell

### If you have installed the Docker version of ESMira
We have provided an Update for the Docker container. All you need to do is `cd` to the `docker-compose.yml` file of ESMira and run: `docker compose pull && docker compose up -d --remove-orphans`

### If you have installed the native PHP version of ESMira
You will have to contact your IT administrator to update the PHP installation on the server.

---
We want to stress again, that you need to update PHP on your server **as soon** as possible!
