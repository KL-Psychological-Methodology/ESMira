You might be aware, that a critical security vulnerability, called [PHP2Shell](https://en.wikipedia.org/wiki/PHP2Shell), has been disclosed on 2026-10-21 in PHP.
PHP drives large parts of the internet and the vulnerability allows to execute malicious code on vulnerable servers.

ESMira is also built on PHP, meaning all ESMira servers are at risk and need to be updated as soon as possible.

> **Important**: This is not a vulnerability in ESMira itself but the technology that allows you to run it. As a result, the server update through the ESMira web interface will **not** resolve this vulnerability.

## How to fix PHP2Shell

### If you have installed the Docker version of ESMira
We have provided an update for the Docker container which includes the patched [PHP version 8.5.12](https://www.php.net/releases/8_5_12.php).

To update, you need to `cd` to the `docker-compose.yml` file of ESMira and run:
```shell
docker compose pull && docker compose up -d --remove-orphans
```

### If you have installed the native PHP version of ESMira
You will have to contact your IT administrator to update the PHP installation on your server.
